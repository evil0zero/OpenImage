# Development artifact inventory

- The source archive contains C++20 sources, CMake presets, bundled core dependency sources, license notices, documentation, and test and benchmark drivers.
- The Windows x64 archive contains the command-line and desktop executables, the same engineering documentation, and core dependency notices. It requires the Microsoft VC++ x64 runtime. The desktop also requires a separate Qt 6.8.3 MSVC x64 installation.
- The evidence directory contains test and build output and benchmark samples. The screenshots directory contains captures of the two Windows Qt appearances.
- The release blocker report identifies the unimplemented and unqualified parts of the production contract.
